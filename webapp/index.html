What it does

momst solves the Multi-Criteria Minimum Spanning Tree problem on complete weighted graphs with NSGA-II, optionally combined with one of three Pareto local search operators. Chromosomes are Prufer sequences, so every individual decodes to a valid spanning tree.

VariantLocal search
baseNone (pure NSGA-II)
PRPath Relinking
PLSPareto Local Search
TSTabu Search

How this page works

This page runs a JavaScript port of the R package, including R's random number generator. With the same instance, parameters and seed it returns the same Pareto front as the R package, which is checked automatically on every deployment.

The same analysis in R

library(momst)
inst <- generate_instance(n = 10, num_obj = 2, seed = 12345)
res  <- run_momst(instance = inst, n = 10, num_obj = 2, variant = "PLS",
                  iterations = 2, pop_size = 30, max_generations = 30,
                  seed = 2026, verbose = FALSE)
plot_pareto_front(res)

# Or the interactive app, locally
momst::run_app()

# Uniform Crossover for Prufer Sequences

Uniform Crossover for Prufer Sequences

## Usage

``` r
uniform_crossover(pool, pop_size, cross_rate)
```

## Arguments

- pool:

  Numeric matrix `[pop_size x (n - 2)]`.

- pop_size:

  Integer (must be even).

- cross_rate:

  Numeric in \\0, 1\\.

## Value

Integer matrix `[pop_size x (n - 2)]`.

# Random Mutation on Prufer Sequences

Random Mutation on Prufer Sequences

## Usage

``` r
random_mutation(population, pop_size, mut_rate)
```

## Arguments

- population:

  Numeric matrix `[pop_size x (n - 2)]`.

- pop_size:

  Integer.

- mut_rate:

  Numeric in \\0, 1\\.

## Value

Integer matrix `[pop_size x (n - 2)]`.

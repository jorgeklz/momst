# Plot a Pareto Front (2-objective case)

Plot a Pareto Front (2-objective case)

## Usage

``` r
plot_pareto_front(result, show_dominated = FALSE)
```

## Arguments

- result:

  List returned by
  [`run_momst`](https://jorgeklz.github.io/momst/reference/run_momst.md).

- show_dominated:

  Logical.

## Value

Invisible NULL.
